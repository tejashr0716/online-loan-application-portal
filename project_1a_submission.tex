\section{2. Architecture Overview \& Underwriting Engine}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Underwriting Engine:} Evaluates applicant Fixed Obligation to Income Ratio (FOIR). For applicant net income exceeding existing debt obligations, sanctions are computed using the reducing balance EMI formula:
    $$EMI = \frac{P \times r \times (1+r)^n}{(1+r)^n - 1}$$
    \item \textbf{Draft Recovery \& State Machine:} Persistent local storage cache automatically recovers incomplete applications upon page refresh, preventing data loss.
    \item \textbf{Accessibility \& UX:} Conforms to WCAG 2.1 AA standards with ARIA roles, live regions for form validation alerts, keyboard tab navigation, and responsive touch controls.
\end{itemize}
